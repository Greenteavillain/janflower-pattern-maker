# 잔꽃 패턴 메이커 🌸

무한 캔버스에 잔꽃 도장을 찍어 나만의 패턴을 만드는 웹 앱입니다.
별도 설치 없이 브라우저에서 바로 동작하는 단일 HTML 파일로 만들어졌어요.

## ✨ 기능

- **무한 캔버스** — 드래그로 화면 이동(Space), 휠/버튼으로 확대·축소
- **잔꽃 도장 & 브러시** — 클릭·드래그로 패턴 그리기
- **미러 축** — 화면 중앙 축을 기준으로 좌우 대칭 패턴
- **격자(G)** — 정렬용 그리드 표시
- **회전(R)** — 도장 90° 회전
- **랜덤 채우기** — 보이는 영역을 랜덤으로 한 번에 채우기
- **배경 전환** — 베이지 / 투명 배경
- **실행취소**

## 🚀 사용하기

별도 빌드가 필요 없습니다. `index.html`을 브라우저에서 열기만 하면 됩니다.

라이브 데모는 GitHub Pages에서 확인할 수 있어요. (저장소 설정 → Pages)

## 🛠 기술

순수 HTML + CSS + JavaScript (Canvas API). 외부 라이브러리·의존성 없음.
